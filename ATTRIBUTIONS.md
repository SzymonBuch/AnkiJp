# Data sources & attribution

All bundled kanji data is generated by the one-off scripts in `scripts/` (`npm run data:pipeline`).
The output lives in `src/data/kanji.json`. The following sources are used and each is
redistributed under its own license. This file summarizes them and the application shows a
condensed version of these credits.

## jpdb.io

- URL: <https://jpdb.io>
- Data used: kanji keywords (main English meaning), radical decompositions ("Composed of"),
  written mnemonics, and example sentences with furigana and English translations.
- Method: the kanji page `https://jpdb.io/kanji/<glyph>` is scraped once by
  `scripts/fetch-jpdb.mjs` (cached in `scripts/out/pages/`).
- License / terms: content on jpdb is used for the purposes of this offline learning app.
  Please respect jpdb's terms of service when running the pipeline. The example sentences
  shown by jpdb originate from Tatoeba (see below).
- jpdb also powers the reading statistics shown as a reference; readings in this app are
  bundled from KANJIDIC via kanjiapi.dev (see below).

## Tatoeba

- URL: <https://tatoeba.org/search> · dumps: <https://downloads.tatoeba.org/exports/>
- Data used: Japanese example sentences and their English translations (used as a fallback
  for kanji with too few examples on jpdb).
- Method: `scripts/fetch-tatoeba.mjs` downloads the official dumps
  (`jpn_sentences.tsv.bz2`, `eng_sentences.tsv.bz2`, `links.tar.bz2`), filters sentences
  per kanji, and generates furigana with Kuromoji.
- License: **CC BY 2.0** — https://creativecommons.org/licenses/by/2.0/
  Contributors to tatoeba.org own copyright of their sentences; redistribution follows the
  CC BY 2.0 license. We attribute the source in the application.

## Kuromoji

- URL: <https://github.com/atilika/kuromoji>
- Data used: morphological analysis / readings for generating furigana in the Tatoeba
  fallback sentences.
- License: **Apache License 2.0**.

## kanjiapi.dev

- URL: <https://kanjiapi.dev>
- Data used: the official 1,006 教育漢字 list (grades 1–6, post-2020 reform), on/kun
  readings, full English meanings, stroke counts, JLPT hints and unicode codepoints.
- Method: `scripts/fetch-kyoiku.mjs` queries `https://kanjiapi.dev/v1/kanji/grade-{1..6}`
  and the per-character endpoint `/v1/kanji/<glyph>`.
- Notes: kanjiapi.dev derives its data from the KANJIDIC file (see below) and is used with
  permission per its API terms.

## KANJIDIC (EDRDG)

- URL: <https://www.edrdg.org/kanjidic/kanjidic.html>
- Data used: the underlying readings, meanings and grade information distributed via
  kanjiapi.dev.
- License: the EDRDG license grants free use of the KANJIDIC file for all non-commercial
  and commercial purposes provided the attribution notice is reproduced.
  See the full license: <https://www.edrdg.org/edrdg/licence.html>
